# RISC-V eXpress

**RISC-V eXpress (RVX)** is an integrated hardware–software framework for developing MCU-class RISC-V SoCs with user-defined hardware accelerators.

<p class="rvx-funding">Developed by <a href="https://etri.re.kr/eng/main/main.etri"><strong>ETRI</strong></a>, South Korea, with support from the ICT R&amp;D Program of MSIT/IITP (No. 2018-0-00197).</p>
