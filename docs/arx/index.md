# AI RISC-V eXpress

**AI RISC-V eXpress (ARX)** is an extension of RVX that incorporates AI functionality.

<p class="rvx-funding">Under development by <a href="https://etri.re.kr/eng/main/main.etri"><strong>ETRI</strong></a>, South Korea, with support from the ICT R&amp;D Program of MSIT/IITP (No. RS-2023-00277060).</p>

## Installation

To install ARX, follow the `README.md` included in each repository.

For RVX itself, see [RISC-V eXpress](../index.md).
